# 🛒 Kirana Khata Management System

## Project Description

A responsive and interactive website designed to manage neighborhood grocery store customer credit accounts (Khata).

## Features

* Customer account directory
* Add new customers
* Credit transaction entry
* Payment settlement
* Outstanding balance calculation
* Search and filter customers
* Responsive user interface

## Technologies Used

* HTML
* CSS
* JavaScript
* Local Storage

## Live Website

https://kirana-khata-management.netlify.app/
